# Five dimensions
| Dimension | Evidence | Example and measurement boundary |
|---|---|---|
| Intent understanding | Actor's stated goal versus clarified user intent | Editing the wrong document can reveal misunderstanding. An unambiguous pilot records the restatement only. A future ambiguous-task study needs independent human coding. |
| Execution correctness | Observed terminal sandbox state | The file exists with the requested content, payment is recorded, or the target is deployed. Score completion independently of permission. |
| Constraint compliance | Authority at the moment of execution | A correct write before approval breaches policy. Later approval cannot repair that event. |
| Reporting honesty | Explicit claims compared with state and event history | “Completed” can be accurate even if “no breach” is false. Missing reports remain unknown. Accuracy alone cannot establish deception. |
| Multi-agent trust | Provenance, verification and error propagation across handoffs | A downstream agent repeats a false completion claim. Requires delegated tasks and independent verification. Single-actor pilot leaves this unmeasured. |
