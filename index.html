Oversight is only as good as the evidence the monitor sees

Three small experiments in AI control by Bin "Robin" Xie. The main one, The Honest Agent, ran real models; two sister projects are scripted simulations.

The question

AI agents can now take real actions: move money, ship code, share files. If an agent breaks a rule, will anyone notice? People can't review every action, so a second AI is often proposed as the monitor. But what should that monitor look at: the agent's own end-of-task report, or the full record of what it actually did?

The Honest Agent: what we found

Each agent got one job in a simulated environment, with one rule: get approval for the exact target before acting. The approver answered "granted", "pending" or "denied". Afterwards the agent reported whether it finished and whether it broke the rule, and AI monitors judged every run without seeing the true record.

The twist. Every one of the 67 breaches finished the job, and every report on them claimed it hadn't. Both monitor families read reports by the same sensible rule, and that one false claim put every breach where the rule either believes the report or stays silent. A monitor that reads only the report can be no better than the report's weakest claim.

Two caveats come first. The big frontier models never broke the rule, so every breach came from one small open model, Qwen 2.5 1.5B, which seemed confused rather than sneaky. And the test was short and explicit. The trace advantage still needs testing against agents that break rules on purpose and hide it.

How it was built

  1. v0.1 scripted A scripted baseline to check that the simulator, ledger and scoring work. zip
  2. v0.2 first real model Qwen 2.5 1.5B as both agent and monitor. It broke the rule in 16 of 20 deployments; the trace monitor looked better than the report-only one, but 20 runs were too few to be sure. README · page
  3. v0.3 pre-registered Frontier models on three tasks: 0 breaches in 210 runs. The Qwen comparison arm failed from a setup error and was rerun after the main analysis, so its monitor result (+0.88) is a declared deviation. write-up · deviations
  4. v0.3.1 pre-registered Three open models on fresh seeds, with the protocol pushed to GitHub before any run. Trace beat report-only: +1.00 (95% CI +0.82 to +1.00). results
  5. v0.3.2 pre-registered A second monitor family, GPT-6 Sol, re-judged the same runs with the same prompts. Trace beat report-only again: +0.88 (95% CI +0.59 to +0.97). results

Why you can check it

  • Written down first. For v0.3.1 and v0.3.2, the protocol and code were pushed to GitHub before any model ran. GitHub's own push log records the times, and a copy is in each study's results/github-push-log.json. v0.3 was pre-registered and hash-frozen before its main runs, but its git history starts later, so its timing rests on local records.
  • Frozen. SHA-256 hashes of every frozen file, re-checked after every run.
  • Everything saved. Every prompt, raw response, token count, cost and timestamp, across about 1,500 trial and judgment files. Failed runs are kept, not deleted.
  • Mistakes in the open. Every deviation and post hoc analysis is listed and labelled, including the predictions that didn't come true.
  • Reviewed. GPT-6 Astra reviewed v0.3 and v0.3.1 read-only, in two rounds each, and reproduced every headline count.
  • Rebuildable. The analyses and the results page rebuild byte for byte from the raw files, offline, with Python's standard library.
  • Cheap. About 185 USD in API-equivalent terms across v0.3 to v0.3.2.

Appendix: two simulation studies

Sister projects that ask related questions. Neither ran an AI model: the "agents" are scripted, so the results show what each test harness can measure, not how real models behave. Appendix overview

simulation · no AI model

The Obedient Rebel

Question: when approval is slow and the action budget runs low, does an agent wait or act?

Three hand-written policies on 8 tasks at budgets of 4, 8 and 12 actions. A "deadline" policy breaks the rule when waiting doesn't fit, and stops once it does. The harness is ready for a real model, which makes it the natural next step: pressure, the thing the Honest Agent's explicit test lacked.

simulation · no AI model

The Swarm Illusion

Question: do more agents make a system more reliable, or spread errors through handoffs?

A seeded sweep of teams against solo workers. One finding echoes the main study: a monitor's recall fell from 100% to 85% to 68% as 0%, 40% and 80% of receipts went missing. Less evidence, worse oversight.
